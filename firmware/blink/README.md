# Перший USB-тест: Blink

Окремий скетч для вашої ESP32 на 38 контактів, без підключеної периферії.
Перемикає тільки GPIO2: 500 мс HIGH / 500 мс LOW. GPIO2 керує
світлодіодом саме цієї плати: власник підтвердив блимання 12.11.2026.
Постійний індикатор живлення може залишатися ввімкненим.

На цьому комп’ютері, з кореня проєкту:

```sh
sh tools/test_blink.sh
```

Сценарій компілює цей скетч, записує його замість поточної програми через
`/dev/cu.usbserial-0001`, а потім протягом максимум 12 секунд читає Serial
(115200 бод). Потрібні локальні Arduino CLI/core та Python pyserial, які вже
є в цьому середовищі. Інший порт можна передати першим аргументом.
Якщо завантаження зупинилося на `Connecting`, утримуйте BOOT до початку запису.

`Serial test PASS` означає, що запущена програма надсилає послідовні перемикання
GPIO2 з інтервалом близько 500 мс без перезапуску. Це не вимір світла:
блимання потрібно побачити на самій платі. Якщо світлодіод не блимає,
з’ясувати його підключення; не перебирати інші GPIO навмання.

Логи: `validation/blink-build.log`, `blink-upload.log`, `blink-serial.log`.
Основну прошивку машинки й її збірку цей тест не змінює.

12.11.2026: скетч скомпільовано (300495 байтів програми, 20696 байтів RAM).
Після дозволу запуску поза sandbox прошивку записано через USB; esptool
підтвердив контрольні суми. Плата: ESP32-D0WD-V3 rev. 3.1, flash 4 МБ.
Serial-тест отримав 12 послідовних перемикань GPIO2 рівно через 500 мс
(1009…6509 мс), без перезапуску у цьому інтервалі. Власник підтвердив
візуальне блимання світлодіода. USB-запис, запуск і Blink-тест успішні.
