# Готові образи Майстерні v0.3

Плата: **ESP32 DevKit V1 30-pin / ESP-WROOM-32, flash 4 МБ**, Arduino-ESP32 3.3.0. Не ESP32-C3/S3. Програмно зібрано та перевірено; на фізичній платі поки не випробувано.

| Файл | Призначення |
|---|---|
| [mandrivnyk-esp32-ota.bin](mandrivnyk-esp32-ota.bin) | Wi-Fi оновлення через «Для вчителя»; лише application image |
| [mandrivnyk-esp32-usb.bin](mandrivnyk-esp32-usb.bin) | Перше встановлення / відновлення через esptool, offset **0x0**; весь 4 МБ образ **замінює NVS** |
| [manifest.json](manifest.json) | Розміри, SHA256, ціль, core, відбитки всіх вихідних файлів firmware |
| [SHA256SUMS](SHA256SUMS) | Контрольні суми завантажених образів |

Схема розділів: два app по 1 966 080 байтів, `min_spiffs`. Майстерня та 3D-гайд включені в образ, окремий запис файлової системи не потрібен.

**Звичайний шлях першого встановлення:** [Arduino IDE / CLI](../README.md). Для підготовленого вчителя з esptool 5:

```sh
esptool --chip esp32 --port /dev/PORT --baud 460800 write-flash 0x0 firmware/release/mandrivnyk-esp32-usb.bin
```

Команду виконують із кореня проєкту, замінивши `/dev/PORT` фактичним портом. Перед USB: S1 вимкнути, зняти AA, від’єднати J5. Після запису прочитати новий Teacher PIN через Serial 115200; повторити калібрування. Не подавати USB і регулятор 5 В одночасно.

Для OTA потрібна вже встановлена наша прошивка, вчительський PIN та підтвердження фізичною кнопкою. **USB-образ не можна передавати як OTA.** Образ bootloader також має ESP32 заголовок, тому лише першого байта недостатньо для вибору правильного OTA файла; використовуйте правильне ім’я та SHA256.

Відтворення пакета після успішної збірки: `python3 tools/package_workshop.py`. Жоден сценарій цього комплекту не прошиває пристрій автоматично. Після зміни коду спочатку повторити збірку й тести.
