# Візуальне програмування Мандрівника v0.2

## Основне середовище — власна українська майстерня

У браузері працює Blockly 13.3.0 з українським перекладом, циклами, умовами, змінними й спеціальними блоками машинки. Редактор міститься у flash ESP32; після USB-підготовки вчителем діти відкривають `http://192.168.4.1` через Wi-Fi робота. Повна [інструкція майстерні](../web/README.md), [приклади `.mcar`](../web/examples), [протокол](workshop-protocol.md).

Стандартні блоки Blockly: числа, арифметика, логіка, порівняння, повторення, while/until, if/else, змінні. **Власна реалізація цього проєкту:** блок початку, рух/окремі мотори/боки, сенсори, P-стеження, Kp, батарея, компілятор MCAR2, виконавець C++, збереження, API та OTA. Blockly сам по собі не прошиває ESP32 і не містить цих модулів.

Дитяча програма передається через Wi-Fi як байткод і виконується автономно. Повний `.bin` оновлюється окремо через вчительське OTA; збірка C++ виконується на комп’ютері вчителя. Це самостійний продукт, без імпорту `.sb3`, спрайтів, сцени, хмарних облікових записів або сумісності з усіма блоками Scratch.

Цільова компіляція ESP32, браузерні сценарії й виконання байткоду у C++ перевірені програмно. Реальний робот/OTA по радіоканалу ще не випробуваний. [Звіт](../validation/report.md).

## Підготовка PictoBlox учителем

Установити desktop PictoBlox, вибрати ESP32 та Upload mode. Записати версію й ОС у протокол. **Зберегти C++ прошивку та калібрування перед експериментом**: PictoBlox завантажує власну програму; наша вебсторінка після цього зникає. Для повернення повторно прошити C++ код, відкалібрувати. Не давати двом середовищам одночасно відкривати serial port.

До роботи учнів створити «Мої блоки» із назвами нижче. Це рецепти для вчителя, не готове протестоване `.sb3` розширення. Внутрішні стандартні блоки: подія старту ESP32, змінна, арифметика, if, repeat, wait, analog read, PWM output, digital read/write. Точна мова написів залежить від локалізації PictoBlox.

1. `Стоп`: встановити PWM=0 для GPIO 16,17,18,19,23,25,26,27.
2. `Швидкість (s)`: змінна speed = max(0,min(180,s)).
3. `Мотор (pin1) (pin2) (v)`: спочатку обидва PWM=0; при зміні знака чекати 0,1 с; якщо v≥0, PWM pin1=abs(v), pin2=0, інакше навпаки. Параметр v обмежити ±180. Не використовувати блок повороту сценічного спрайта як команду коліс.
4. `Боки (left) (right)`: Motor(16,17,left), Motor(23,25,left), Motor(18,19,right), Motor(26,27,right).
5. `Вперед`: Боки(speed,speed); `Назад`: Боки(−speed,−speed); `Ліворуч`: Боки(0,speed); `Праворуч`: Боки(speed,0).
6. `Безпечне очікування (секунди)`: repeat (секунди×50): перевірити кнопку GPIO13, FAULT 21/22; якщо LOW — Стоп і припинити програму; wait 0,02 с. Для першого заняття потрібен постійний нагляд і S1. Апаратні шунти та запобіжники залишаються. Програмний захист батареї з C++ НЕ зберігається після перепрошивання: додати читання GPIO39, переведення у VBAT_SW за калібруванням мультиметром і зупинку нижче 4,2 В. Без цього не вважати PictoBlox-проєкт готовим до автономного уроку.
7. `Прочитати очі`: ADC GPIO32/33/34/35/36; діапазон у встановленій версії виміряти білим/чорним. Не припускати, що він завжди 0–1023 чи 0–4095. Зберегти окремі white/black для кожного каналу; нормалізувати й обмежити 0–1000.
8. `Крок за лінією`: сума ваг×значення / сума значень, Kp×помилка; `Боки(clamp(speed+c),clamp(speed−c))`; усі білі або всі чорні → Стоп. Учням спочатку показувати лише зовнішній блок, згодом розкрити вміст.

Перед читанням кнопки налаштувати GPIO13 як INPUT_PULLUP; доступність цього режиму в установленій версії перевіряє вчитель. Якщо його немає, потрібне зовнішнє підтягування 10 кΩ до 3V3 та оновлення джгута/BOM. Кнопку фізичного старту перевірити до руху. Простий учнівський стартовий сценарій: подія ESP32 → Стоп → чекати натискання й відпускання GPIO13 → Швидкість 80 → Вперед → Безпечне очікування 2 → Стоп. Після перевірки вчитель зберігає власний стартовий проєкт у встановленому PictoBlox. Готовий імпортований файл тут не заявлений, бо його неможливо було випробувати в PictoBlox.

## Заняття в новому редакторі

Уроки 1–4: категорія «Рух», швидкість, час; квадрат — «повторити 4 рази». Уроки 5–7: «Лінія й очі», калібрування з меню «Для вчителя», темрява 0–1000, Kp і стеження. Урок 8: надсилання, автономний запуск, `.mcar`, пульт `/control` для ручного керування.

Сім старих `.txt` у `lessons/programs` зберігаються для `/control`. Новий редактор має чотири вбудовані приклади та відповідні файли `.mcar` у `web/examples`. Змінювати блоки можна без перепрошивання; нові фізичні модулі потребують змін електрики, прошивки й блоків.
