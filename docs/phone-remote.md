# Пульт із телефона — перша версія

Діти програмують у наявній Blockly-майстерні на комп’ютері. Програма передається USB, а телефон надсилає події через локальну Wi-Fi-мережу ESP32. Інтернет, застосунок і роутер для пульта не потрібні. Мобільний редактор блоків і власні назви кнопок поки не реалізовані.

## Перший запуск

1. Відкрий майстерню в настільному Chrome/Edge. Підключи ESP32 через USB.
2. Якщо плата відповіла зі старою версією базової прошивки, майстерня запропонує оновлення. Якщо відповіді немає, спочатку віднови USB-зв’язок через «Перевірити підключення», відпустивши BOOT; сама відсутність відповіді не потребує перевстановлення. Поточний ідентифікатор середовища — `gpio2-v5`; звичайні старі програми лишаються сумісними. Перед перевстановленням збережи проєкт: налаштування встановлює початковий приклад.
3. Обери «Ідеї → Світлодіод із телефона», потім «Прошити».
4. Розгорни «Пульт із телефона · Wi-Fi»: тут назва мережі `Mandrivnyk-…` та індивідуальний пароль плати. Ці дані також є в USB-журналі після перевірки плати. Не публікуй журнал із паролем.
5. На телефоні підключись до цієї мережі. Підтвердь використання мережі без інтернету, якщо телефон запитує.
6. Відкрий **http://192.168.4.1** у звичайному браузері, не у вікні перевірки інтернету. Натисни «Підключити пульт».
7. «Блимнути» виконує три спалахи GPIO2; «Кнопка 1 ↕» тримає GPIO2 увімкненим до відпускання. На платі потрібен LED саме на GPIO2.

Після нового USB-завантаження старий сеанс анулюється. Перезавантаж сторінку пульта, щоб отримати новий набір кнопок. USB потрібен для програмування, але не для подальшого керування за наявності належного окремого живлення.

## Блоки й правила виконання

### Одна кнопка вмикає й вимикає GPIO19

Після встановлення `gpio2-v5` обери «Ідеї → Телефон → перемикач GPIO19» та завантаж програму на плату. Приклад використовує звичайні категорії «Телефон», «Керування», «Логіка», «Змінні», «Числа» та «Піни»:

```text
коли на телефоні натиснуто «Кнопка 1»
  якщо стан = 0
    пін GPIO19 увімкнути
    встановити стан = 1
  інакше
    пін GPIO19 вимкнути
    встановити стан = 0
```

Створи змінну `стан` через «Змінні». Вона починається з нуля автоматично: не додавай встановлення нуля на початку кожного натискання. Для гілки «інакше» відкрий налаштування блока «якщо». Обробник відпускання для цього прикладу не потрібний. Між натисканнями `стан` та рівень виходу зберігаються, поки пульт підключений. Змінна спільна для всіх обробників. Перезапуск плати, завантаження програми, «СТОП», втрата зв’язку або помилка виконання скидають змінні в нуль. Для перевірки без LED можна додати в гілки консольні повідомлення «Увімкнено» та «Вимкнено».

### Без світлодіода: консоль під блоками

Після оновлення базової прошивки до `gpio2-v4` у меню «Ідеї» обери приклад «Телефон → консоль» і натисни «Прошити». Залиш USB підключеним. У браузері телефона відкрий пульт і натисни «Кнопка 1»: у консолі під блоками з’явиться «Кнопку отримано!», за секунду — «Готово». Додаткові компоненти не потрібні.

Блок «Консоль → вивести в консоль [текст]» працює всередині обробників телефона, циклів, умов і власних блоків. Поки підтримується сталий однорядковий текст, до 120 байтів UTF-8 (приблизно 60 українських літер). Повідомлення надходять від ESP32, а не від симуляції браузера. Час у консолі — час отримання на комп’ютері. Історія містить останні 200 рядків, очищується кнопкою «Очистити» та при оновленні сторінки; на платі історія не зберігається.

Читання консолі й звичайне USB-завантаження використовують спільне з’єднання без повторного відкривання порту. Перед перевстановленням базової прошивки консоль звільняє порт; після готовності відновлюється. Для перегляду потрібен браузерний USB-режим Chrome/Edge; старий локальний режим не має живої консолі. Службові відповіді й Wi-Fi-пароль до консолі не потрапляють.

Прошивка виводить не більше 10 повідомлень за секунду; надлишкові повідомлення пропускаються, щоб не затримувати керування та зупинку. При наступному доступному повідомленні консоль показує кількість пропущених. Додай в цикл паузу хоча б 0,1 секунди. Перше встановлення базової прошивки, як раніше, записує тест блимання: після нього окремо завантаж приклад консолі.

- Категорія «Телефон»: «коли на телефоні натиснуто/відпущено [команду]».
- Вісім назв: Вперед, Назад, Ліворуч, Праворуч, Блимнути, Танець, Кнопка 1, Кнопка 2. Назва не визначає поведінку: її задають вкладені команди GPIO, цикли та умови.
- Пульт показує лише кнопки з обробником натискання. Наявність обробника відпускання робить кнопку утримуваною (↕). Відпускання без відповідного натискання — помилка компіляції.
- Один обробник на пару «команда + подія». Не можна додати автономний запуск при ввімкненні до програми пульта. Порожній початковий блок дозволено залишити.
- Після ввімкнення програма пульта чекає команди. Обробники виконуються по одному; змінні починаються з нуля при завантаженні програми та зберігаються між подіями. Нова команда під час виконання відхиляється; пульт переходить у стан зупинки, без черги майбутніх рухів.
- Перед відпусканням усі налаштовані виходи вимикаються, потім виконується його обробник зі збереженими змінними. Після завершення обробника останні задані рівні виходів зберігаються. Втрата зв’язку та STOP вимикають виходи й скидають змінні. У старих програмах, що покладалися на вимкнення після завершення, додай явний блок вимкнення або обробник відпускання.
- «СТОП», приховування сторінки, втрата фокусу та скасування дотику зупиняють сеанс. Для нового запуску треба підключити пульт знову.
- Сервер дозволяє один активний сеанс. Heartbeat кожні 200 мс; після 900 мс без прийнятих повідомлень ESP32 зупиняє програму й виходи. Лічильники відкидають застарілі повідомлення. HTTP обслуговується окремим завданням, щоб повільний клієнт не блокував перевірку тайм-ауту.
- Аналогові входи для програм пульта — лише ADC1 (GPIO32–39 відповідно до моделі пінів), оскільки Wi-Fi використовує ADC2. Для звичайних автономних USB-програм Wi-Fi вимкнено.
- Експорт окремого Arduino-коду та старий локальний режим компіляції не підтримують події телефона; використовуй браузерне USB-завантаження.

## Межі та приймання

Це локальний навчальний пульт, не система функціональної безпеки. Зупинка означає вимкнення налаштованих виходів, а не гарантію миттєвої механічної зупинки. Потрібні доступне фізичне вимкнення живлення моторів і перевірка конкретного драйвера.

До заняття перевір на справжніх Android та iPhone: підключення без інтернету, утримання й відпускання, вихід за межі кнопки, згортання браузера, блокування екрана, втрату Wi-Fi, одночасні два телефони, STOP під час довгого очікування/циклу, USB-оновлення та перезапуск. Перші моторні перевірки проводь із піднятими колесами. Автоматичні тести й компіляція не замінюють цих апаратних випробувань.

Тести: `node --test web/tests/remote-control.test.mjs`, `npm test --prefix web`, `npm run test:e2e --prefix web -- remote-control.spec.js`. Пакування прошивки: `sh tools/build_browser_firmware.sh`; ця команда не прошиває підключену плату.
