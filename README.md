# StepBy Robotics

**Робототехніка крок за кроком для українських шкіл.** Платформа для гуртка: конструктор електричних підключень, програмування блоками, запуск на ESP32, керування з телефона та матеріали для вчителя.

«Мандрівник» — перший навчальний робот і майстерня в складі платформи. Планується інтеграція зі [StepBy School](https://github.com/vmyronovych/stepby-school); зараз проєкти працюють окремо.

## Швидкий запуск

```sh
npm ci --prefix web
npm run dev --prefix web
```

Відкрий `http://localhost:5173`. Без плати можна створювати блоки й схеми; для USB потрібні настільний Chrome/Edge та ESP32. Приклад «Ідеї → Телефон → перемикач GPIO19» демонструє змінну, умову та перемикання одним натисканням; він потребує базової прошивки `gpio2-v5`.

```sh
npm test --prefix web
npm run build:site --prefix web
```

На GitHub Pages публікується `web/dist`. У репозиторії обери **Settings → Pages → GitHub Actions**, потім запусти **Actions → Classroom website → Run workflow → deploy_pages**. Звичайні push і PR запускають перевірки без публікації. Деталі: [розгортання та USB-доступ](docs/classroom-web-usb.md).

## Навчальний комплект «Мандрівник»

**Пульт із телефона:** блоки «коли на телефоні натиснуто/відпущено» → USB-завантаження → Wi-Fi-пульт на ESP32. Без додаткових компонентів почни з прикладу «Телефон → консоль»: повідомлення плати з’являються під блоками через USB. [Підключення, правила безпеки та межі першої версії](docs/phone-remote.md). Апаратне приймання з Android/iPhone ще потрібне.

**USB-майстерня веде за станом плати:** анімація підключення → дозвіл браузера → перевірка / перше налаштування → блоки. Від’єднання повертає екран підключення без втрати проєкту.


**Браузерна USB-майстерня:** Blockly → «Прошити» → ESP32 через Web Serial у Chrome/Edge. Після одноразового встановлення базової прошивки алгоритми передаються без BOOT і без повного перепрошивання. Учнівським ПК не потрібні Node.js чи Arduino IDE. Є статична збірка для GitHub Pages; Windows-приймання ще попереду. [Клас, підключення та публікація](docs/classroom-web-usb.md).

**10.11.2026: повну 3D-машинку та покрокове складання перебудовано на уточненому корпусі.** Обидві пластини використовують контур із 72 отворами з `/chassis-review.html`: 255 × 150 × 3 мм, чистий проміжок 30 мм. Відсік 62 × 58 × 18 мм перенесено під нижню платформу; кроки описують кріплення скотчем і встановлення AA знизу. Оновлено PDF, OBJ та браузерний гайд. Контур оцінений за фото, посадки моторів/опор/електроніки залишаються схематичними. Архів v0.3 і готові release-образи не перевидані. [Межі геометрії](docs/assembly-guide.md).

Український комплект для 3–4 класу: механіка, електрика, програмування та вісім занять. Оновлено 12.10.2026. Поточне програмне середовище — USB-майстерня: Blockly у браузері та автономні програми на ESP32. Матеріали **v0.3 / Wi-Fi OTA** належать попередній версії. Цільова прошивка ESP32 успішно скомпільована; апаратні випробування попереду.

**Почати з редактора:** [інструкція майстерні](web/README.md) · [підключення та перше USB-налаштування](docs/classroom-web-usb.md).

Для перегляду на комп’ютері: `npm ci --prefix web`, потім `npm run dev --prefix web` і відкрити `http://127.0.0.1:5173`. Головна сторінка відкриває USB-майстерню. Кнопка «Продовжити без плати» дозволяє редагувати проєкт без ESP32. Старий Wi-Fi-редактор прибрано з вебзастосунку.

**Статус: проєкт для виготовлення й випробування першого зразка. Не видавайте його класу як перевірений серійний набір.** Розміри отриманого шасі, струм моторів та посадка кронштейна датчика ще потребують вимірювання. Збірка для ESP32 має окремий статус у [протоколі перевірки](validation/report.md). Ілюстрації використовують контур за фото та виміряні габарити; це не креслення для свердління.

## Інтерактивне складання

Посилання **«Роздивитися машинку»** відкриває 3D-гайд: 23 кроки, обертання, масштабування, підсвічування й анімація встановлення деталей. Прямий шлях `/#assembly`. Корпус спільний з PDF та уточненим переглядом; вебмоделі HW-627, ESP32 38P, плати розширення та мотора відтворено за вашими новими фото. Контакти можна натискати. Точні кріплення потребують замірів. [Як користуватися гайдом](docs/assembly-guide.md).

## Що обрано

- Куплене двоповерхове шасі ArduinoKit 71480450, без повторної купівлі моторів, коліс або відсіку.
- Чотири AA NiMH; обране місце відсіку — під нижньою платформою на двосторонньому скотчі; після приклеювання перевірити утримання та зазор.
- Поточний комплект за фото: ESP32 на 38 контактів, фіолетова плата розширення ESP32S 38P/4, драйвери DRV8833 HW-627, жовті мотори-редуктори. Старі PDF/схема описують 30P і Pololu #2130; їхнє обмеження струму 0,8 А та модифікації шунтів не підтверджені для HW-627. Вебперегляд оновлено, електричне підключення нового комплекту ще потребує перевірки.
- Датчик Pololu QTR-MD-05A #4245; п'ять аналогових каналів, живлення 3,3 В.
- Стабілізатор 5 В Pololu S13V30F5 #4082 для електроніки; мотори живляться від батарей окремою гілкою.
- C++ / Arduino-ESP32 3.3.0; автономне стеження за лінією, браузерне керування, швидкість, Kp, калібрування, Blockly зі змінними, циклами та умовами.

## Порядок роботи вчителя

1. Прочитайте [дослідження](docs/hardware-research.md) та [архітектуру](docs/architecture.md).
2. Заповніть [карту вимірювань](docs/mechanical-layout.md). Внесіть реальні числа в `assembly/sources/geometry.json`; повторно створіть посібник. Не використовуйте демонстраційні координати як розмітку отворів.
3. Закупіть [додаткові компоненти](docs/bom.md) лише для одного пілотного робота. Підтвердьте наявність і ціни перед замовленням партії.
4. Дорослий паяє, ізолює, готує роз'єми, перевіряє драйвери й вимірює струми (старі модифікації Pololu не застосовувати до HW-627). Діти працюють лише з холодними, підготовленими деталями.
5. Перевірте [електричну схему](docs/wiring.md), запрограмуйте плату за [інструкцією](firmware/README.md), проведіть усі випробування з `validation/bench-checklist.md`.
6. Роздрукуйте [посібник A4](assembly/assembly-manual.pdf) у кольорі, 100%, без масштабування. Пройдіть його самостійно на реальному шасі перед уроком.
7. Почніть [заняття 1](lessons/lesson-01.md). Двоє учнів на робота: конструктор і перевіряльник; міняються ролями кожні 10 хвилин.

## Програмування дітьми

Основне середовище — **USB-майстерня Мандрівника** на Blockly. Діти складають алгоритми з керування GPIO, ШІМ, пауз, умов і циклів, створюють власні команди з параметрами. Конструктор підключень передає в блоки назви підключених пінів; схема та програма зберігаються разом у `.mcar`.

Кнопка «Прошити програму» передає алгоритм через USB; ESP32 зберігає й запускає його автономно. Для першого налаштування плати майстерня показує окремі підказки. Встановлювати компілятор C++ на учнівські комп’ютери не потрібно. [Запуск у класі](docs/classroom-web-usb.md).

Попередні матеріали про Wi-Fi, OTA, пульт `/control` і текстові файли `lessons/programs` описують історичну прошивку. Цих функцій немає в поточному вебредакторі. Формат Scratch `.sb3` не підтримується.

Оновлений PDF складання описує ту саму геометрію, що й вебгайд; його сторінки старого вебінтерфейсу стосуються `/control`. Новий Blockly-інтерфейс описано в `web/README.md`.
