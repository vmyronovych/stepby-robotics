# Third-party software

Blockly 13.3.0: https://github.com/RaspberryPiFoundation/blockly
Licensed under Apache License 2.0. The unmodified license is included in `BLOCKLY-LICENSE.txt` and served by the robot at `/licenses.txt`. Blockly supplies the visual editor and Ukrainian localization. Custom robot blocks, compiler, UI and firmware integration are project-specific.

Build/test tools and their licenses are recorded by the exact npm dependency lockfile. No PictoBlox source, logos, commercial extensions or branding are used. All production assets are bundled locally; no CDN, web fonts, telemetry or account service is required.

Three.js 0.186.1: https://threejs.org/ — MIT License, included in `THREE-LICENSE.txt` and `/licenses.txt`. It renders the interactive assembly model and provides OrbitControls. Model geometry and Ukrainian instructions come from this project's shared PDF/manual sources. No external 3D assets are fetched.
