# Заняття 04. Швидше й повільніше

> **Майстерня v0.2 (Blockly):** Змінюй число у блоці «швидкість» категорії «Рух». Після кожної зміни: «Надіслати роботу», потім «Запустити». Основна адреса `http://192.168.4.1`. Нижче назви старого інтерфейсу «Мої блоки» та текстові `.txt` стосуються `/control`; PictoBlox — окремий необов’язковий варіант. [Інструкція нового редактора](../web/README.md).

**Вік:** 8–10 років. **Час:** 35–45 хв. **Мета:** Порівняти швидкість за однакового часу.

Потрібно: прийнятий учителем робот, заряджені NiMH, телефон/планшет, білий папір, чорна матова стрічка, лінійка й аркуш спостережень. Урок проходить у власному браузерному редакторі робота. Для PictoBlox нижче наведено окреме перенесення, а не готовий імпорт.

## Перед початком

Учитель перевіряє допуск першого зразка, вільну підлогу та доступ до S1. Діти не паяють, не торкаються коліс у русі й не переставляють роз’єми під живленням. Один учень складає блоки, другий звіряє порядок; через 10 хв міняються ролями. Перший дослід нового руху — з піднятими колесами.

## Хід заняття

5 хв — прогноз; 20–25 хв — досліди; 5 хв — обговорення; 5 хв — вимкнення та прибирання.

1. Підготуйте смугу завдовжки щонайменше 2 м без перешкод.
2. Порівняйте два відрізки, кожен по 2 с, зі швидкостями 60 і 100. Перед запуском зробіть прогноз.
3. Для точного порівняння розділіть програму на два окремі запуски з однієї мітки. Запишіть три результати для кожної швидкості.
4. Спробуйте швидкість 0. Усі колеса повинні стояти. Якщо 60 недостатньо для старту, учитель змінює початкове значення після перевірки струму.

## Нотатка вчителю про блоки

Нативний PWM є в PictoBlox; учительські «Мої блоки» обмежують speed до 0…180. Функція розгону основної прошивки автоматично не переноситься.

[Порівняння середовищ і рецепти функцій](../docs/programming.md). Якщо завантажували PictoBlox, для наступних браузерних уроків поверніть C++ прошивку й перевірте калібрування.

Наприкінці: СТОП → S1 вимкнено → робот на полицю. AA заряджає дорослий у зовнішньому NiMH зарядному пристрої; у роботі заряджання немає.
